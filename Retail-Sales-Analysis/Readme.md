📊 Retail Sales Performance Analysis using Python
📌 Project Overview

This project focuses on analyzing retail sales data to understand revenue trends, customer behavior, and regional performance.

The objective of this analysis is to generate meaningful business insights using Python and help support data-driven decision-making.

This project demonstrates practical data analysis skills required for a Data Analyst role.

🎯 Business Objectives

Analyze total revenue performance

Identify top-performing product categories

Compare regional sales contribution

Study customer segmentation based on age and gender

Analyze monthly revenue trends

Calculate key performance metrics (KPIs)

🛠 Tools & Technologies Used

Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook

📂 Dataset Description

The dataset contains retail sales transaction records with the following fields:

Order_ID

Order_Date

Customer_ID

Gender

Age

Region

Product_Category

Quantity

Price

A new column Revenue was created using:

Revenue = Quantity × Price

🧹 Data Cleaning & Preparation

Converted Order_Date to datetime format

Checked and handled missing values

Verified duplicate records

Created new columns (Revenue, Month, Age Group)

Performed feature engineering for better analysis

📊 Key Performance Indicators (KPIs)

Total Revenue

Total Orders

Average Order Value (AOV)

Total Quantity Sold

These KPIs help measure overall business performance.

📈 Exploratory Data Analysis (EDA)

The following analysis was performed:

1️⃣ Revenue by Region

Compared total revenue across different regions.

Identified highest contributing region.

2️⃣ Revenue by Product Category

Analyzed category-wise sales performance.

Found top-performing product category.

3️⃣ Monthly Revenue Trend

Studied revenue growth pattern over months.

Identified increasing sales trend.

4️⃣ Age Group Analysis

Segmented customers into age groups.

Compared revenue contribution by age category.

5️⃣ Gender-wise Analysis

Compared revenue generated by male and female customers.

🔍 Key Insights

Electronics category generates the highest revenue contribution.

West region shows strong overall sales performance.

Revenue demonstrates steady growth from January to March.

Customers aged 30–40 contribute significantly to total revenue.

The average order value indicates strong purchasing behavior.

💡 Business Recommendations

Focus marketing efforts on high-performing regions.

Increase stock availability for top-performing categories.

Launch targeted campaigns for high-revenue age groups.
